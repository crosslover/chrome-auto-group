# 03: 生成可提交 Chrome Web Store 的扩展包

**What to build:** 提供完整可加载、可打包的扩展交付物，让用户能自行提交到 Chrome Web Store。

**Blocked by:** 02: 跨站导航换组并支持手动整理

**Status:** ready-for-agent

- [ ] 完整扩展可在 Chrome 中作为未打包扩展加载并运行。
- [ ] 生成可供用户提交的扩展压缩包，包含运行所需的扩展文件与资源。
- [ ] 提交包中不包含运行时远程代码或网络服务依赖，符合本规格的本地处理约束。
- [ ] 提供简明的本地加载和打包说明。
- [ ] 不执行 Chrome Web Store 上架或开发者账号操作；商店页面素材不属于本票据范围。
