# 02: 跨站导航换组并支持手动整理

**What to build:** 标签页跨站导航时跟随网站标识换组，同时让用户可以整理当前窗口中未分组的普通网页；现有手动分组继续保持原样。

**Blocked by:** 01: 新标签页按网站标识自动分组

**Status:** resolved

- [x] 已分组标签页跨站导航后，当前组标题符合 ADR 的网站标识判断规则时，标签页移入当前窗口的新网站标识对应的组。
- [x] 当前组名不符合网站标识判断规则时，导航后保持在原组。
- [x] 不保存标签页分组来源；手动创建且名称与有效网站标识相同的组按 ADR 约定处理。
- [x] 提供“整理当前窗口”入口，只整理尚未分组的普通网页标签页。
- [x] 手动整理时保留所有已有标签组及其中的标签页。
- [x] 扩展行为测试 seam 覆盖跨站导航、普通手动组保留、同名组歧义和手动整理结果。


## Answer

- 已分组标签页在 URL 变化时，当前标题可由网站识别规则原样产生才换组；未知域名主体、数字网站标识、本地主机及 IP 均按同一规则判断，不记录分组来源。
- 跨站导航创建或复用所在窗口的目标组；常规手动组与特殊 URL 保持原样，同名手动组按 ADR-0001 接受的歧义处理。
- 增加工具栏弹窗与“整理当前窗口”按钮，仅整理该窗口未分组的 HTTP/HTTPS 网页，复用已有目标组并保留全部已有分组；不扫描启动会话。
- 沿用真实 Chrome 扩展行为测试 seam，补充导航、手动组、同名歧义、窗口隔离、特殊 URL 和整理重复执行场景。修正测试读取时旧组被浏览器移除的瞬时竞争。
- TDD 已验证：原实现无法跨站换组、缺少工具栏入口；数字标题 `1688` 的回归测试在修复前失败、修复后通过。
- `pnpm typecheck` 通过；最终 `pnpm test` 完整 28 项通过，包含原有启动恢复与 worker 休眠回归。
- `code-review` 两轴审查完成：Standards 0 项、Spec 0 项未解决发现；数字标题问题已补回归并修复。
