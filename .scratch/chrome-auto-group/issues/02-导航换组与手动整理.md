# 02: 跨站导航换组并支持手动整理

**What to build:** 标签页跨站导航时跟随网站标识换组，同时让用户可以整理当前窗口中未分组的普通网页；现有手动分组继续保持原样。

**Blocked by:** 01: 新标签页按网站标识自动分组

**Status:** ready-for-agent

- [ ] 已分组标签页跨站导航后，当前组标题符合 ADR 的网站标识判断规则时，标签页移入当前窗口的新网站标识对应的组。
- [ ] 当前组名不符合网站标识判断规则时，导航后保持在原组。
- [ ] 不保存标签页分组来源；手动创建且名称与有效网站标识相同的组按 ADR 约定处理。
- [ ] 提供“整理当前窗口”入口，只整理尚未分组的普通网页标签页。
- [ ] 手动整理时保留所有已有标签组及其中的标签页。
- [ ] 扩展行为测试 seam 覆盖跨站导航、普通手动组保留、同名组歧义和手动整理结果。
